# Кандидатний словник для генератора парольної фрази

> **Цей словник не пройшов локалізаційний review.** Механічні фільтри
> застосовані й закриті тестами, але редакторської перевірки не було. Доки її
> немає, UI **не оголошує ентропію фрази** («72 біти») і **не показує індикатор
> сили** — §7 плану і блокер 2 промпту Фази 2.

## Джерела

| Джерело | Що дає | Ліцензія | Зріз |
|---|---|---|---|
| [LibreOffice `dictionaries/uk_UA/uk_UA.dic`](https://github.com/LibreOffice/dictionaries/blob/master/uk_UA/uk_UA.dic) | питомість слова | **MPL 1.1** (`README_uk_UA.txt`) | 2026-07-25 |
| [hermitdave/FrequencyWords `content/2018/uk/uk_full.txt`](https://github.com/hermitdave/FrequencyWords) | уживаність (частота) | **MIT** | 2026-07-25 |

Обидва джерела потрібні, і кожне закриває конкретний провал іншого:

- сам лише частотний список зібраний із субтитрів і рясніє російськими
  словами (`что`, `это`, `ты` — у першій двадцятці); перетин зі словником їх
  відсікає;
- сам лише словник дає механічно бездоганний список із `абцуг`, `авгіт`,
  `айсор` — фразу з таких слів неможливо ані запам'ятати, ані продиктувати.

`brown-uk/dict_uk` відхилено попри вищу якість даних: він під **GPL-3.0**, а
цей репозиторій публічний і власної ліцензії не має. Пакет LibreOffice —
похідний від dict_uk, але поширюється під MPL 1.1, тож саме він і взятий.
Похідний файл `uk-4096.ts` лишається під MPL 1.1.

## Процедура

```bash
node --experimental-strip-types apps/web/scripts/build-wordlist.mjs
```

Скрипт детермінований: ті самі зрізи джерел дають той самий файл. Він завантажує
обидва джерела (мережа потрібна лише тут — застосунок нічого не завантажує) і
застосовує фільтри з [`filters.ts`](filters.ts) у такому порядку:

1. довжина 4–9 літер (`hasAllowedLength`);
2. лише малі літери українського алфавіту — без апострофа, дефіса, латиниці й
   великих літер, тобто без власних назв (`isUkrainianLowercase`);
3. слово присутнє в словнику LibreOffice;
4. слово не містить жодного стему зі стоп-списку (`hasNoMedicalStem`);
5. далі — жадібний прохід **за спаданням частоти**:
   - один представник на кожен унікальний префікс перших 4 літер, щоб
     автодоповнення не вимагало вводити слово повністю (`hasUniquePrefixes`);
   - слова, що збігаються після оглушення дзвінких у кінці, пропускаються
     (`devoicedForm`, `hasNoHomophones`) — інакше `гриб` і `грип` у фразі не
     розрізняються на слух;
6. перші 4096 слів, відсортовані за абеткою.

На зрізі 2026-07-25 фільтри дали 7670 придатних кандидатів, тобто відбір мав
запас у ~87%.

## Стоп-список

`STOP_STEMS` у [`filters.ts`](filters.ts) містить перелік із промпту Фази 2
(`невро`, `симптом`, `мігрен`, `епілепс`, `склероз`, `здоров`, `діагн`, `біль`,
`напад`, `лік`) і сусідні поля тієї самої семантики — хвороба, тіло, смерть.
Розширення безкоштовне: кандидатів удвічі більше, ніж потрібно, а фраза для
щоденника неврологічних симптомів не має складатися зі слів про хворобу.

## Що лишається редакторові

Механічні фільтри не ловлять:

- омоформи й слова, що плутаються на слух поза правилом оглушення;
- слова з тривожною або інтимною конотацією, які не потрапили в стоп-список;
- діалектизми й запозичення, які формально є в словнику, але не впізнаються;
- слова, незручні для диктування по телефону.

Доки редактор не пройшов список, `REVIEWED_BY_LOCALIZATION_EDITOR` лишається
`false`, а UI говорить лише те, що фразу згенеровано застосунком.
